Thanks for buying this extension!

Buying this extension means you are supporting the development of Paymenter and helping us to keep it free for everyone.

To install this extension just go to your Paymenter admin area, then to Extensions > Install Extension and upload the zip file you downloaded when buying this extension.

After installing, go to Extensions > Manage Extensions and enable the Proxmox extension.

This extension requires to build the css files. Please read the instructions here: https://paymenter.org/development/theme/assets

For more information on how to use this extension, please visit the [Proxmox documentation](https://paymenter.org/docs/extensions/servers/proxmox).

If you require assistance with this extension, please go to the [Paymenter Discord](https://discord.gg/kJWDZ86NUZ) and ask for help in the 3rd party support channel.
